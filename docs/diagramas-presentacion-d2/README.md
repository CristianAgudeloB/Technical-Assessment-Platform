# Diagramas para la presentación

Cada archivo corresponde a un espacio reservado en el documento Word.

Compile con D2 desde la raíz del proyecto:

```bash
d2 docs/diagramas-presentacion-d2/01-entendimiento-del-problema.d2 docs/diagramas-presentacion-d2/01-entendimiento-del-problema.svg
```

Se recomienda SVG para mantener nitidez al insertarlo en Word. Use el archivo cuyo número coincide con el marcador del documento.

El archivo `08-seguridad-y-aislamiento.d2` acompaña la sección adicional sobre Docker, sandboxing y controles de ejecución.
