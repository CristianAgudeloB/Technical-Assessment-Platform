# Diagramas D2

Cada archivo `.d2` corresponde a un marcador de insercion del documento Word.

Para compilar un diagrama con D2 instalado:

```bash
d2 docs/diagramas-d2/01-casos-de-uso.d2 docs/diagramas-d2/01-casos-de-uso.svg
```

Se recomienda exportar a SVG o PNG e insertar la imagen bajo el marcador con el mismo numero en el DOCX.
